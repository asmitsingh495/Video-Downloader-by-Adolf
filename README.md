# Video-Downloader-by-Adolf
A simple and user-friendly desktop video downloader built with Python, CustomTkinter, and yt-dlp.

Paste a supported media URL, select where you want to save the file, and start the download directly from the graphical interface—without manually using the command line for downloading.

✨ Features
🔗 Paste a video/media URL
📁 Select a custom download folder
⬇️ Start downloads directly from the GUI
📊 Real-time download progress bar
📈 Download percentage display
❌ Cancel an active download
🧵 Background downloading to keep the GUI responsive
📂 Automatically creates the selected folder if needed
⚠️ Error handling and download status messages
🖥️ Clean and simple CustomTkinter interface
🐧 Works as a Python application on Linux
🪟 Can be packaged as a Windows application using a Windows build environment
🛠️ Technologies Used
Python
CustomTkinter
yt-dlp
Threading
PyInstaller

# 🎬 How to Use
Open Video Downloader by Adolf.
Paste a supported and authorized media URL.
Click Browse to choose a download folder.
Click Download.
Monitor the download progress.
Click Cancel if you want to stop the active download.
After completion, the downloaded file will be saved in the selected folder.

# 🧪 Application Flow
Paste URL
    ↓
Select Download Folder
    ↓
Click Download
    ↓
yt-dlp Processes URL
    ↓
Progress Bar Updates
    ↓
Download Complete
    ↓
File Saved to Selected Folder
